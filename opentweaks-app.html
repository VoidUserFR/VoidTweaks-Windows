How to use: copy a command and run it in PowerShell (open as Administrator for anything marked admin). This page only shows and copies commands — it can't change your system by itself. The matching engine Invoke-OpenTweaks.ps1 can apply a whole category, make a System Restore point first, and show which tweaks are already applied with -Status.

Every tweak marked reversible ships a Revert command. For an old, slow PC, start with the Recommended set and reboot afterwards.
