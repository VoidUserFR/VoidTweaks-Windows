FAQ

Frequently asked questions

Is it safe?

Every change is reversible and shown in plain language, and a restore point is offered before changes. The full source is public. Still — these are real system changes, so only apply what you understand and keep "Restore point first" on.

Does it phone home / collect data?

No telemetry, no accounts. It only talks to the network when you run a test, install an app, or when it checks GitHub for a new version.

Why does Windows say "Windows protected your PC" / "Unknown publisher"?

VoidTweaks isn't code-signed yet (a signing certificate costs money), so Windows SmartScreen shows an "unrecognized app / unknown publisher" warning on first run, and some antivirus engines flag self-contained .NET apps that touch system settings. It's a false positive — the full source is right here on GitHub.

To run it now: More info → Run anyway. To get it cleared properly (Defender + SmartScreen submission steps), see report-false-positive.md. The only instant, reliable fix is a code-signing certificate.

Will it break Windows Update or my PC?

No tweak blocks updates unless you explicitly apply one that does, and it's reversible. Keep "Restore point first" on and you can always roll back.

Installer or portable — which?

The installer sets up shortcuts and is easiest. The portable zip needs no install — unzip and run VoidTweaks.exe, keeping the .json/.ps1 files beside it. Both are self-contained; .NET is not required.

Do I need to run it as administrator?

Only for admin-level tweaks (marked with an ADMIN badge). The app shows a banner and a "Restart as administrator" button when elevation is needed. Everything else works without it.

How do I undo a change?

Flip the tweak's toggle back off, use Undo last, Revert all, or restore to a point in Tools → Restore points. Almost everything is fully reversible.

Is it really free?

Yes — MIT licensed, no paywall, no "Pro" tier, no feature held hostage. If it helped, a ⭐ on GitHub genuinely helps it reach more people.

What languages are supported?

Nine: English, Portuguese, Russian, French, German, Spanish, Chinese, Italian and Japanese. Switch in Settings.

How do I uninstall it?

If you used the installer: Windows Settings → Apps → VoidTweaks → Uninstall. Portable: just delete the folder. Any tweaks you applied stay until you revert them — revert what you want first, or restore to an earlier point.

Which Windows versions work?

Built for Windows 11 (x64). Many tweaks work on Windows 10 too, but it's tested and designed for 11.

Can I contribute?

Yes — issues and PRs are welcome, especially new tweaks (add them to tweaks.json), translations and bug reports. See the GitHub repo.

Didn't find your answer?

Open an issue on GitHub — bugs and questions both welcome.
