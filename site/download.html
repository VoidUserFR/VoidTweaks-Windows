"Windows protected your PC" on first run? VoidTweaks is unsigned, so SmartScreen warns — it's a false positive. Click More info → Run anyway. Full explanation in the FAQ, and submission steps in report-false-positive.md.

Verify your download

Each release ships a SHA256SUMS file. To check a download matches, run in PowerShell:

Get-FileHash .\VoidTweaks-Setup.exe -Algorithm SHA256

and compare it to the value in the release's checksums file.

Build from source

Prefer to build it yourself? You'll need the .NET 10 SDK:

cd VoidTweaksApp && dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true

Everything a tweak does is visible in tweaks.json — no hidden actions.
