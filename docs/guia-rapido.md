# VoidTweaks — Guia Rápido 🚀

Otimizador de Windows 11 **grátis, aberto e 100% reversível**. Nada é escondido, nada "liga pra casa".

## 1. Instalar

- Baixa o **`VoidTweaks-Setup.exe`** na [página de releases](https://github.com/VoidUserFR/VoidTweaks-Windows/releases/latest) e roda.
- Ou usa o **`VoidTweaks-portable.zip`**: descompacta e abre o `VoidTweaks.exe` (sem instalar). Mantém os ficheiros `.json` e `.ps1` ao lado do `.exe`.
- Não precisa de .NET — já vem tudo dentro.

> Se o antivírus reclamar: é normal em apps que mexem no sistema. O código é todo aberto no GitHub.

## 2. Abrir como administrador

Clica com o botão direito → **Executar como administrador**. Alguns tweaks precisam disso (há um aviso dentro do app se faltar).

## 3. Antes de mexer

- Deixa **"Ponto de restauro primeiro"** ligado (já vem ligado). Cria um ponto de restauro antes das mudanças.
- Só aplica o que entenderes. Cada tweak mostra o que faz e o nível de risco.

## 4. Usar

- **Barra lateral:** Início · Otimizar · Ferramentas · Correções · Definições.
- Cada tweak é um botão: **verde = aplicado, vermelho = não**. Clica para aplicar, clica de novo para reverter.
- **★** marca um favorito.
- Botão **Scan** (topo) atualiza o estado de todos os tweaks.

## 5. Coisas úteis

- **Limpar tudo** — temp, cache, lixeira, DNS, RAM, num clique.
- **Gestor de pontos de restauro** — cria, lista e volta atrás se algo correr mal.
- **Testes** — stress de CPU, rede e benchmarks.
- **Idioma** — Definições → Português (e mais 8 línguas).

## Se algo correr mal

Reverte o tweak (clica de novo) **ou** usa o gestor de pontos de restauro para voltar ao estado anterior. Tudo é reversível.
